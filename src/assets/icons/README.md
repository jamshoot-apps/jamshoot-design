# Built-in icons

These eight SVGs are from Ionicons, under the MIT license in `LICENSE.txt`.
The theme icons (`sunny-outline`, `moon-outline`, `contrast-outline`) use the
[v5.5.2 source](https://github.com/ionic-team/ionicons/tree/v5.5.2/src/svg), replacing
the original theme-control artwork previously shipped under those names.
Their geometry is unchanged from upstream; fixed root dimensions and titles are
removed, and black strokes use `currentColor`.

`MANIFEST.sha256` records the shipped SVG bytes. Site and docs builds copy the MIT
notice to `licenses/ionicons.txt`; retain that file when distributing the output.
